# 安全说明

## 数据保护范围

公开版默认从空列表开始，数据保存在 `%LOCALAPPDATA%\3XuiPanelManagerPublic\data`，不自动读取其他版本的配置和账号。需要保留的数据应由用户自行备份。

本机账号由 Windows DPAPI 加密。它保护静态存储的账号，不能防御已控制当前 Windows 用户会话的程序。程序使用账号连接服务器时，账号仍需在内存中解密。

`.vpsaccounts` 使用用户设置的迁移密码加密，仅包含面板账号和已配置的隧道密钥。导入时目标必须已有相同 ID 的服务器配置，程序不会创建未知服务器。迁移步骤见 [README](../README.md)。导出文件应视为敏感备份，使用长且唯一的密码，并将文件与密码分开保管。遗失密码后无法通过本程序恢复。

服务器地址、用户名、备注和浏览器数据也可能暴露个人信息。数据目录不应提交到公共仓库；分享截图、日志和错误信息前应人工检查。

## SSH 与面板访问

SSH 功能使用 Windows OpenSSH。首次连接时应核实主机指纹，SSH 账号仅授予所需权限，私钥应限制访问权限。不要将私钥、口令或带凭据的连接地址放入仓库。

新增服务器界面只支持 HTTP / HTTPS 地址，未提供 SSH 隧道的图形配置助手。高级用户可在公开版自身数据目录的 `统一管理\服务器列表.json` 中，为对应服务器手动配置 `Tunnel` 对象，字段为 `Host`、`Port`、`User`、`RemotePort`、`LocalPort`、`KeyFile`、`KnownHostsFile`。`KeyFile` 指向由当前 Windows 用户使用 DPAPI 加密保存的 OpenSSH 私钥文件，并非明文私钥；`KnownHostsFile` 指向自行核验主机指纹后的 `known_hosts` 文件。两条文件路径均应位于公开版数据目录内并使用相对路径。隧道面板地址应指向匹配 `LocalPort` 的本机 HTTP 入口。修改前关闭程序并备份配置；本项目不附带密钥或主机信任记录。

请优先为管理面板配置 HTTPS、强密码和访问限制。只管理自己拥有或获得授权的服务器，并核实界面中的目标地址后再执行操作。

## 提交前检查

运行 `scripts\Test-PublicPrivacy.ps1`，再人工检查 `git diff --cached` 和 `git status --short`。自动扫描只能发现已定义的特征，无法保证识别全部隐私信息。

不要提交运行数据、账号导出、SSH 密钥、浏览器资料、日志、带账号的截图或个人备份。`.gitignore` 不会移除已经被 Git 跟踪的文件；若敏感信息已经公开，应立即撤销或更换相关凭据，并清理 Git 历史。

## 报告问题

公共 Issue 中仅提供脱敏后的复现步骤、程序版本和错误信息。请勿公开密码、Token、私钥或完整连接资料。安全问题应通过仓库所有者提供的私密渠道报告；若仓库尚未配置该渠道，请先询问合适的联系方式。
